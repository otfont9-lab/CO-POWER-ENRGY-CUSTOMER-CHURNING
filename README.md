# CO-POWER-ENRGY-CUSTOMER-CHURNING
CoPower is an end-to-end machine learning pipeline designed to predict customer churn for an energy and gas provider.
 Initial iterations of this model suffered from severe data leakage (yielding an artificial 1.0 ROC-AUC) and poor minority-class recall. This repository contains the corrected, production-ready pipeline utilizing robust feature isolation and gradient boosting to accurately identify churners.
